# PitchGenie chosen brand direction

The implementation direction is **Enterprise Intelligence** (Option C in the
visual exploration). Production work should preserve this tone across the
marketing surface, workspace, generation forms, document views, and exports.

## Working rules

- Use navy, white, cool gray, and a restrained cyan/teal accent.
- Prefer clear information architecture, strong tables/navigation, and subtle
  depth over decorative gradients or glass effects.
- Keep hierarchy dense enough for consultants and sales teams while preserving
  generous spacing around the actual proposal/deck output.
- Make system states explicit: saving, generated, limited, failed, and export
  unavailable should never rely on color alone.
- Keep copy direct and operational. The product is a dependable business-output
  workspace, not a novelty chatbot.
